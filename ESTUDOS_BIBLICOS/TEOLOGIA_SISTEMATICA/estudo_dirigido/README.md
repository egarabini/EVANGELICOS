# Estudo Dirigido — Planos de Aprendizagem

> **Planos estruturados para estudo profundo de cada capítulo**

---

## Sobre Esta Pasta

Esta pasta contém planos de estudo dirigido para cada capítulo da Teologia Sistemática, organizados em 6 etapas para maximizar o aprendizado.

---

## Estrutura de 6 Etapas

Cada plano de estudo segue esta estrutura:

### 1. 🔥 Aquecimento

Três perguntas-gatilho para ativar o conhecimento prévio:
- O que você já sabe sobre este tema?
- Quais dúvidas você tem?
- Por que este tema importa?

### 2. 📖 Leitura Guiada

Leituras focadas do capítulo com seções específicas:
- Leia a seção Perguntas centrais
- Leia a seção Explicação e Base Bíblica
- Leia as Notas

### 3. 🧠 Conceitos-Chave

Definições essenciais para memorizar:
- Termo 1: Definição
- Termo 2: Definição
- Termo 3: Definição

### 4. ✍️ Teste de Entendimento

Questões para verificar o aprendizado:
- Questões objetivas (múltipla escolha)
- Questões dissertativas

### 5. 💭 Reflexão Pessoal

Espaço para aplicação à vida:
- Como isso se aplica à sua vida?
- O que você vai fazer diferente?

### 6. 🏁 Consolidação

Síntese e autoavaliação:
- Rubrica de autoavaliação (0-5)
- Farol final: 🟢 dominado · 🟡 revisar · 🔴 reler
