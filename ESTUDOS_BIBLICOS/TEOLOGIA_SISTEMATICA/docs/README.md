## Metadados de Vídeo

Ao adicionar um vídeo, use este formato:

```markdown
# Título do Vídeo

- **Autor/Canal**: Nome do autor ou canal
- **Duração**: HH:MM:SS
- **Link**: https://url-do-video
- **Data de acesso**: DD/MM/AAAA
- **Tópicos abordados**:
  - Tópico 1
  - Tópico 2
- **Notas**: Observações relevantes
```
