# Imagens — Figuras e Diagramas

> **Recursos visuais para ilustrar conceitos teológicos**

---

## Sobre Esta Pasta

Esta pasta contém figuras, diagramas e ilustrações que ajudam a visualizar conceitos teológicos.

---

## Categorias

### Diagramas Teológicos

- Diagramas de doutrinas
- Fluxos de pensamento
- Estruturas conceituais

### Gráficos e Tabelas

- Gráficos comparativos
- Tabelas de referência
- Linhas do tempo

### Imagens Históricas

- Retratos de teólogos
- Locais históricos
- Manuscritos antigos

---

## Como Adicionar Imagens

1. Salve a imagem com nome descritivo
2. Crie um arquivo `.md` com o mesmo nome
3. Documente a fonte e descrição
4. Indique a relevance para o estudo

---

## Formato de Documentação

```markdown
# Nome da Imagem

- **Arquivo**: nome_da_imagem.png
- **Fonte**: https://url-da-fonte
- **Autor**: Nome do autor (se conhecido)
- **Descrição**: O que a imagem mostra
- **Relevância**: Por que esta imagem é relevante
- **Capítulos relacionados**: Lista de capítulos
```
