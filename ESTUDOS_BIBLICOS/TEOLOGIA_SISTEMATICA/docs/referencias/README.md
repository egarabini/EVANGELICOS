## Como Adicionar Referências

1. Crie um arquivo `.md` para cada obra ou categoria
2. Inclua informações bibliográficas completas
3. Adicione resumo e relevância para o estudo
4. Use formatação consistente

---

## Formato de Referência

```markdown
# Título da Obra

- **Autor**: Nome do autor
- **Ano**: Ano de publicação
- **Editora**: Nome da editora
- **ISBN**: xxx-x-xxxxx-xx-x
- **Link**: https://link-para-compra
- **Resumo**: Breve resumo da obra
- **Relevância**: Por que esta obra é relevante
```
