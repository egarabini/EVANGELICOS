# Plano Template Estudo — Templates de Planejamento

> **Templates para criação de planos de estudo e slides**

---

## Sobre Esta Pasta

Esta pasta contém os templates usados para criar planos de estudo e estruturas de slides.

---

## Estrutura

```
plano-template-estudo/
├── template_capitulo.md       ← Template de capítulo
├── template_slide.md          ← Template de slide
└── template_reflexao.md       ← Template de reflexão
```

---

## Templates

### template_capitulo.md

Template para estruturar um capítulo completo:
- Perguntas centrais
- Seções principais
- Definições teológicas
- Notas de rodapé

### template_slide.md

Template para criar slides individuais:
- Título do slide
- Conteúdo principal
- Pílulas de resumo
- Referências bíblicas

### template_reflexao.md

Template para criar reflexões:
- Perguntas de reflexão
- Espaço para resposta
- Aplicação prática

---

## Como Usar

1. Copie o template desejado
2. Personalize conforme o capítulo
3. Siga as convenções de nomenclatura
4. Mantenha a estrutura consistente

---
