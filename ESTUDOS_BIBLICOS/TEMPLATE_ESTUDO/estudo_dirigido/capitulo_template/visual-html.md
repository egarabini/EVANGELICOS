## 🔧 Problemas Técnicos

### Se o Deck Não Abrir

1. **Verifique o caminho**: O arquivo index.html existe?
2. **Navegador**: Tente abrir em outro navegador
3. **Permissões**: Verifique se tem permissão de leitura

### Se as Animações Não Funcionarem

1. **JavaScript**: Verifique se JavaScript está habilitado
2. **Navegador**: Atualize para a versão mais recente
3. **Console**: Abra o console para ver erros (F12)

## INSTRUÇÕES DE USO

### Como usar este template:

1. **Copie** este arquivo para `estudo_dirigido/capitulo_XX/visual-html.md`
2. **Substitua** todos os campos entre chaves `{}` pelas informações reais
3. **Liste todos os slides** do deck
4. **Conecte** cada slide com a seção correspondente do texto
5. **Salve** mantendo o formato markdown

### Campos obrigatórios:

- `## 📺 Deck do Capítulo` — Informações do deck
- `## 📋 Estrutura dos Slides` — Pelo menos capa e encerramento
- `## 🔗 Conexões com o Texto` — Pelo menos uma conexão

### Campos opcionais:

- Todas as outras seções podem ser adaptadas conforme a necessidade.
