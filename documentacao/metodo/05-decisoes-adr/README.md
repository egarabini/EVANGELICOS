# `05-decisoes-adr/` — Decisões (ADRs)

As **leis** do projeto. Uma ADR registra uma decisão estrutural, não uma tarefa.

| Documento | Para quê |
|---|---|
| [como-usar-adr.md](como-usar-adr.md) | Como escrever, numerar e versionar ADRs — e a **lista mínima de decisões** que todo projeto novo precisa tomar antes da primeira DEM. |
| [ADR-000-template.md](ADR-000-template.md) | O template MADR a copiar para cada nova ADR. |

> As ADRs são o Pilar A do método (ver [`../00-visao-geral/filosofia.md`](../00-visao-geral/filosofia.md)). Nenhuma DEM pode contrariar uma ADR `Accepted`.
